블로그 글 목록

고칠 글을 누르거나, 새 글을 직접 쓰세요.

글 수정

첫 화면

홈페이지를 열면 큰 영상 위에 보이는 글씨입니다. 화면 3장이 차례로 넘어갑니다.
배경 영상은 여기서 못 바꿉니다 — 영상 파일은 폰에서 올리기엔 너무 커서 소통마케팅센터에 말씀해 주세요.

공지 팝업

홈페이지를 열면 가운데 뜨는 안내창입니다. 손님이 「오늘 하루 보지 않기」를 누르면 그날은 안 보이고, 다음 날 다시 보입니다.

연락처

여기서 바꾸면 홈페이지 모든 화면·블로그 글 전부의 번호가 같이 바뀝니다. 글이 많아 1~2분 걸립니다 — 끝날 때까지 이 화면을 닫지 마세요.

사진첩

갤러리 화면에 보이는 사진·영상입니다. 폰 사진을 고르면 크기는 자동으로 줄어듭니다. 넓게를 켜면 두 칸을 차지합니다.

자주 묻는 질문

질문은 손님 말투 그대로, 답은 첫 문장에 바로 결론을 쓰세요. 구글·AI 검색이 이 답을 그대로 가져갑니다.

사용법 — 처음이시면 눌러 보세요

1. 이 화면을 휴대폰 첫 화면에 두기

  • 아이폰: 아래 가운데 [공유] → [홈 화면에 추가]
  • 갤럭시: 오른쪽 위 [⋮] → [홈 화면에 추가]
  • 비밀번호는 이 기기에서 한 번만 넣으면 됩니다.

2. 블로그 새 글 쓰기

  1. 위 메뉴 [블로그] → [+ 새 글 쓰기]
  2. 제목: 지역 + 무엇 (예: 영월 동강 래프팅, 1박2일 얼마인가요?)
  3. 요약: 이 글의 답을 한두 문장으로. 검색 결과에 그대로 보입니다.
  4. 태그: 쉼표로 (예: 동강래프팅, 영월래프팅)
  5. 본문: [소제목]은 질문으로, 바로 아래 첫 문장에 답을 적으세요.
  6. [저장] → 1~2분 뒤 홈페이지 블로그에 올라갑니다.

3. 쓴 글 고치기 · 사진

  • 글 목록에서 고칠 글을 누르세요.
  • 사진 넣기: 넣을 자리를 한 번 누르고 → [사진 넣기]. 여러 장 한 번에 됩니다.
  • 사진 빼기: 사진을 눌러 빨간 테두리가 생기면 → [고른 사진 빼기]

4. 첫 화면 · 공지 팝업

  • [첫 화면]: 화면 3장의 큰 글씨와 한 줄 소개를 바꿉니다. 큰 글씨는 줄마다 엔터, 색으로 강조할 말은 글씨 안에 있는 그대로 적으세요.
  • 배경 영상은 여기서 못 바꿉니다. 바꾸시려면 소통마케팅센터로 연락 주세요.
  • [공지 팝업]: 시즌 안내·할인·휴무를 적으세요. 끝나면 [팝업 보이기]를 끄고 저장하면 더 이상 안 뜹니다.

5. 연락처 · 사진첩 · 자주 묻는 질문

  • 연락처: 한 곳에서 바꾸면 홈페이지 전체와 블로그 글 전부가 같이 바뀝니다. 글이 많아 1~2분 걸리니 끝날 때까지 기다려 주세요. 네이버 플레이스·카카오맵 번호도 똑같이 맞춰야 검색이 헷갈리지 않습니다.
  • 사진첩: [+ 사진]으로 폰 사진을 올리고, 유튜브·인스타는 주소를 붙여 넣으면 됩니다. ↑↓로 순서를 바꾸고 [삭제]로 지웁니다.
  • 자주 묻는 질문: ↑↓로 순서를 바꾸고 [삭제]로 지웁니다. 마지막에 [저장]을 꼭 누르세요.

6. 검색에 잘 걸리는 요령

  • 숫자로 쓰기 — 가격, 시간, 인원, 거리
  • 실제 사진 쓰기, 지어낸 후기 쓰지 않기
  • 글 하나에 주제 하나

7. 실수했을 때 · 안 될 때

  • 저장 전이면 다른 메뉴로 나가면 바뀐 것이 버려집니다. 블로그 본문은 [되돌리기]도 됩니다.
  • 「저장 실패」: 인터넷을 확인하고 [저장]을 다시 누르세요.
  • 저장했는데 안 바뀜: 1~2분 기다린 뒤 홈페이지를 새로고침(휴대폰은 아래로 당기기)
  • 비밀번호가 안 맞음: 관리하는 분께 새 비밀번호를 받으세요.

8. 비밀번호 관리 (관리하는 분)

  • 비밀번호는 카톡 단체방에 올리지 마세요.
  • 직원이 그만두면 [블로그] 화면의 [비밀번호 정하기·바꾸기]로 바꾸세요. 그러면 모든 사람이 새 비밀번호를 넣어야 합니다.
  • 바꿀 때는 이 홈페이지 전용 GitHub 토큰이 한 번 필요합니다.
